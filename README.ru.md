Набор инструментов для **владельцев серверов и мододелов DayZ**.
Разбирает PBO мода, даёт выбрать нужные предметы и собирает готовый
**рекваер-аддон (override)**, который переживает обновления мода. Плюс миграция `types.xml`,
слияние оверрайдов, квесты и лодауты Expansion, спавн-лут, настройка миссии
и строгая проверка JSON/XML.

Работает локально в браузере — без облака, без аккаунта, без установки.

## 🚀 Быстрый старт

```text
1. Положите DayZOverrideBuilder.exe в любую папку и запустите.
2. Откроется чёрное окно — НЕ ЗАКРЫВАЙТЕ его, это и есть программа.
   В браузере откроется вкладка с интерфейсом.
3. Если вкладка не открылась сама — введите в браузере адрес
   из чёрного окна, обычно  http://127.0.0.1:8017
4. Windows SmartScreen может предупредить о новом файле:
   «Подробнее» → «Выполнить в любом случае»  (норма для программ без подписи).
```

> ⚠️ **Программа может ошибаться.** Делайте резервные копии, проверяйте полученные файлы
> перед заливкой на сервер и читайте вкладку **«Журнал»** — там видно каждое действие.

## ✅ Проверка файлов — что именно ловится

Проверка намеренно сделана такой же строгой, как онлайн-валидаторы
(`codebeautify`, `jsonlint`), потому что DayZ молча отказывается грузить файлы,
которые «выглядят» правильными.

<details>
<summary><b>XML — ошибки структуры</b></summary>

<br>

- Мусорный текст **внутри** файла, между тегами (например случайные символы `1231` после `</type>`) —
  формально XML остаётся «правильным», но для игры это ошибка
- Лишний текст до или после корневого тега, несколько корневых тегов
- Повторяющиеся атрибуты в одном теге
- Незакрытые и перепутанные теги
- Голые символы `&` и битые сущности

</details>

<details>
<summary><b>types.xml — смысловая проверка по правилам экономики DayZ (с номером строки записи)</b></summary>

<br>

- `nominal` / `min` / `lifetime` / `restock` / `cost` — целые, не отрицательные
- `nominal` не меньше `min`; `lifetime` не `0`
- `quantmin` / `quantmax` — либо оба `-1`, либо оба `0..100`, причём `min <= max`
- Флаги `count_in_*` / `crafted` / `deloot` — только `0` или `1`
- Проверка имён `category` / `usage` / `value` (тир) / `tag` на опечатки
- Неизвестные или опечатанные теги внутри `<type>`
- Записи `<type>` без `name` и дубликаты `name`

</details>

<details>
<summary><b>cfgspawnabletypes.xml и cfgrandompresets.xml</b></summary>

<br>

- `chance` должен быть числом от `0.0` до `1.0`
- У записей должен быть `name`

</details>

<details>
<summary><b>JSON</b></summary>

<br>

Лишние запятые, одинарные кавычки, комментарии, пропущенные запятые, обрыв файла,
мусор после конца JSON, дубликаты ключей.

</details>

**Ошибки и замечания разделены.** Битый формат и недопустимые значения — это **ошибки**
(файл сломан). Спорная экономика (`nominal < min` и подобное) и незнакомые имена из модов —
**замечания** (грузится, но стоит проверить).

## 📖 Гайд по ссылке (по желанию)

Вставьте ссылку на гайд мода — GitHub wiki, страницу или папку WIKI — и программа скачает его
и подставит описания к параметрам открытого конфига. Гайд кэшируется, поэтому повторные
загрузки работают без интернета.

Доступно на вкладках **Inedia AI**, **Terje**, **Exp. Квесты** и **Exp. Лодауты**.

| Режим | Что даёт |
|---|---|
| **Структурный разбор** | Бесплатно навсегда, без регистраций и ключей |
| **Через ИИ** | Переводит описания на русский, понимает гайды свободным текстом, добавляет кнопку **«Спросить»** — вопрос по гайду своими словами |

<details>
<summary><b>Как включить ИИ-помощника</b></summary>

<br>

Нажмите кнопку **🤖** вверху. Работает с **бесплатными** тарифами:
**Groq**, **OpenRouter** (модели `:free`), **Google Gemini**, **GitHub Models**,
локальный **Ollama** или любой OpenAI-совместимый сервер.

Нужен только API-ключ — получается за пару минут, банковская карта не требуется.

**Приватность:** ключ хранится только у вас в `settings.json`. Нейросети отправляется
текст гайда и *имена* параметров — **значения ваших конфигов не отправляются.**

ИИ можно выключить в любой момент той же кнопкой — программа полностью работает и без него.

</details>

## 🔬 Технические детали

- **Go 1.21**, один статический бинарник со встроенным веб-интерфейсом — без CGO и DLL.
- **Локальный веб-интерфейс** на `127.0.0.1:8017`, управление из браузера.
- **PBO / config.bin** — собственный распаковщик и дебинаризатор (`rap` — чтение и запись
  бинарных конфигов raP).
- **Собственные модули** для types.xml (`typesx`), слияния оверрайдов (`mergecfg`), сверки
  версий (`diffcfg`), квестов и лодаутов Expansion, миссий, спавн-лута, текстур EDDS
  и проверки файлов (`validator`).
- **Покрыто Go-тестами** — `pbo`, `typesx`, `mergecfg`, `diffcfg`, `guide`, `tools`, `validator`.
