DayZ Override Builder v1.10.2
=============================

ЧТО НОВОГО В 1.10.2 - вкладка "Проверка файлов" стала понимать DayZ:
  * Теперь ловится мусорный текст ВНУТРИ файла - между тегами (например
    случайные символы "1231" после </type>). Раньше пропускалось, т.к.
    формально XML оставался «правильным», но для игры это ошибка.
  * Добавлена смысловая проверка types.xml по правилам экономики DayZ
    (с номером строки записи):
      - nominal/min/lifetime/restock/cost - целые, не отрицательные;
      - nominal не меньше min; lifetime не 0;
      - quantmin/quantmax: оба -1 либо оба 0..100, min <= max;
      - флаги count_in_* / crafted / deloot - только 0 или 1;
      - проверка имён category / usage / value(тир) / tag на опечатки;
      - неизвестные/опечатанные теги внутри <type>;
      - записи <type> без name и дубликаты name.
  * cfgspawnabletypes.xml и cfgrandompresets.xml: проверка, что chance -
    число 0.0..1.0, и что у записей есть name.
  * Разделение на ОШИБКИ (файл сломан) и ЗАМЕЧАНИЯ (грузится, но стоит
    проверить): битый формат и недопустимые значения - ошибки; спорная
    экономика (nominal<min и т.п.) и незнакомые имена из модов - замечания.

ЧТО ИСПРАВЛЕНО В 1.10.1 - вкладка "Проверка файлов":
  * Раньше проверка XML пропускала реальные ошибки и говорила "всё
    нормально". Теперь XML проверяется СТРОГО, как онлайн-валидаторы
    (codebeautify): ловятся лишний текст/мусор до или после корневого
    тега, несколько корневых тегов, повторяющиеся атрибуты в одном теге,
    незакрытые и перепутанные теги, голые символы & и битые сущности.
  * JSON по-прежнему проверяется строго (как jsonlint): лишние запятые,
    одинарные кавычки, комментарии, пропущенные запятые, обрыв файла,
    мусор после конца JSON, дубликаты ключей.
  * Добавлен выбор формата файла (types.xml, cfgspawnabletypes.xml,
    cfgrandompresets.xml, JSON, config.cpp/текст). Обычно достаточно
    "Определить автоматически"; выбор формата нужен, если у файла нет
    расширения или надо проверить, что это именно тот файл.

1. Положите DayZOverrideBuilder.exe в любую папку и запустите.
2. Откроется чёрное окно (не закрывайте его) и вкладка в браузере
   с интерфейсом программы. Если вкладка не открылась сама -
   откройте в браузере адрес из чёрного окна (обычно http://127.0.0.1:8017).
3. Windows SmartScreen может предупредить о новом файле:
   "Подробнее" -> "Выполнить в любом случае".
4. Всё работает локально. Интернет нужен только для новой функции
   "Гайд по ссылке" и ИИ-помощника (обе - по желанию).

НОВОЕ В 1.10.0 - "Гайд по ссылке" (вкладки Inedia AI, Terje,
Exp. Квесты, Exp. Лодауты):
  * Вставьте ссылку на гайд мода (github wiki, страница или папка
    WIKI) - программа скачает его и подставит описания к параметрам
    открытого конфига. Гайд кэшируется: повторные загрузки без интернета.
  * Режим "структурный разбор" - бесплатно навсегда, без регистраций.
  * Режим "через ИИ" - переводит описания на русский и понимает гайды,
    написанные свободным текстом. Плюс кнопка "Спросить" - вопрос по
    гайду своими словами.
  * ИИ включается кнопкой [робот] вверху. Работает с БЕСПЛАТНЫМИ
    тарифами: Groq, OpenRouter (:free), Google Gemini, GitHub Models,
    локальный Ollama или любой OpenAI-совместимый сервер. Нужен только
    API-ключ (получается за пару минут, карта не нужна). Ключ хранится
    только у вас в settings.json. ИИ отправляется текст гайда и имена
    параметров - значения ваших конфигов не отправляются.
  * ИИ можно в любой момент выключить той же кнопкой - программа
    полностью работает и без него.

Вкладки: 1-2-3 создание рекваер-аддона | Сверка версий модов |
Types (миграция и оптимизация) | Слияние оверрайдов | Exp. Квесты |
Exp. Лодауты | Спавн-лут | Миссия (+ калькулятор дня/ночи) |
Inedia AI | Terje | Проверка файлов | Журнал.

ВАЖНО: программа может ошибаться. Делайте резервные копии, проверяйте
полученные файлы перед заливкой на сервер и читайте вкладку "Журнал" -
там видно каждое действие. Описания и ответы ИИ сверяйте с гайдом.
